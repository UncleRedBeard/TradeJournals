# The Forge And Shop

Documents the workshop buildout and restoration work, with emphasis on reclaimed timber, durable work surfaces, tool storage, material reuse, and the workspace practices that support the broader preservation portfolio.

## Working Guide

Start with the [shop journal index](trade_journals/README.md). Work within one
shop project or a focused part of its record, such as a bench, utility system,
material-reuse decision, or staging method.

Use the [Flickr inventory](../FLICKR_PUBLIC_ALBUMS.md) to resolve the shop album
and its recorded metadata. Shop photographs may also support a machine or
residence project. Keep workshop decisions here and link to the relevant
project journal for the repair's findings and outcome.

For an update:

1. Read the selected journal and identify the shop problem the addition explains.
2. Record the materials, working method, tradeoffs, and supporting evidence in
   that journal. Keep its progress and outstanding evidence there as well.
3. Update the index when navigation changes, and use the
   [publishing guide](../site_example/README.md#portfolio-publishing) if the
   portfolio selection changes.

Use the [existing validation checks](../MODULE_MAP.md#existing-validation).

## Suggested Journal Topics

- reclaimed timber sourcing, milling, and preparation
- workbench construction and shop fixtures
- layout decisions for woodworking, metalwork, and mechanical restoration
- lighting, power, dust control, and utility integration
- tool restoration, storage, and maintenance
