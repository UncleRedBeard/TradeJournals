# Scanned Project Sketchbooks

This directory preserves complete scans of Shawn's working notebooks. The
drawings document the repeatable planning method used across restoration and
mechanical work: measure existing conditions, map systems, record hidden
conditions, calculate geometry, and plan the sequence before the evidence is
changed by the work itself.

## Working With Shared Scans

Use this guide for source provenance and page assignments. Keep project
interpretation, progress, and outstanding evidence in the relevant journal.
Link to the original scan and identify its pages when documenting a room or
machine; preserve the complete source when it spans several projects.

For an approved source addition, record its identity and page mapping here,
then update only the relevant journal references. Follow changed file and page
links and use the [existing validation checks](../../MODULE_MAP.md#existing-validation).
The [residence](../../01_the_residence_1894/README.md#working-guide) and
[machine](../../03_the_machines/README.md#working-guide) guides describe the
project-level workflows.

## Vespa Electrical Harness Map - September 9, 2023

- Source: [standalone electrical harness
  map](vespa_electrical_harness_map_20230909.pdf)
- Related archive: page 10 of the
  [house project sketchbook](house_project_sketchbook_20260820.pdf)

This one-page scan is the clearer, complete standalone version of the Vespa
electrical planning sheet represented in the master sketchbook. It maps the
turn-signal, horn, headlight, and key-switch circuits, including wire colors,
connector positions, and frame-ground points. The drawing is a shop reference
for preserving the as-found wiring layout during harness removal,
troubleshooting, and reassembly; it is not presented as a factory schematic.
